# 安全升级与部署配置

此次升级停用了三条 `/system/auth/auto-login*` 接口（包括历史凭据兑换）及
`/system/user/forget/password`。它们返回 403。只有实现绑定账户、短时有效、一次性验证
凭据后才能重新提供自助找回功能。管理后台的找回入口会提示联系管理员。

公开注册不再接受角色、创建人或超级管理员字段；额外字段返回 422。
`REGISTER_DEFAULT_ROLE_IDS=[]` 默认不给新用户管理权限，确需授权时由部署管理员配置
经过核实的最低权限角色。第三方登录仍只使用服务端 `OAUTH_DEFAULT_ROLE_IDS`。

管理重置密码需要单独的 `module_system:user:reset` 权限，并始终应用数据范围过滤；
超级管理员账户仍不可被重置。初始化菜单新增了对应按钮，order 追加在用户管理按钮末尾。
已有部署需在菜单管理添加或同步该权限，再只授予有需要的角色。

## 必须更新的生产配置

1. 生成新的随机 JWT 密钥，例如 `python -c "import secrets; print(secrets.token_hex(32))"`，
   将结果设置为 `SECRET_KEY`，通过密钥管理或部署环境注入。不要提交真实密钥。
   生产环境拒绝默认值、示例值、短密钥及明显重复的弱密钥。
2. 轮换密钥后所有旧 JWT 都将失效；清理旧 Redis 访问和刷新会话以及
   `fastapiadmin:auto_login:*`、`oauth_state:*`、`oauth_code:*` 遗留凭据。
   不要对共享 Redis 执行 `FLUSHDB`。访问令牌现在还必须逐字匹配 Redis 留存值，
   HTTP 与 WebSocket 使用相同校验；刷新会拒绝停用用户。
3. 保持生产 Compose 中验证码开启、后端端口仅绑定 `127.0.0.1`，公网统一通过 Nginx。
   API 文档请求同样需要验证码，Referer 不再提供绕过验证或审计的能力。
4. 审查已有操作日志中的密码、令牌、密钥泄露，按保留制度限制访问并清理或脱敏；
   同步处理日志导出、备份和采集系统。新日志仅保留白名单结构字段，敏感及未知字段
   递归替换为 `[REDACTED]`，不回写修改历史日志。
5. 检查现有管理员账户、角色绑定和异常会话，处理历史漏洞可能造成的未经授权变更。

## OAuth 升级

启用前设置精确完整 URL 白名单，例如：

```dotenv
OAUTH_REDIRECT_ALLOWLIST=["https://admin.example.com/login"]
OAUTH_FRONTEND_FALLBACK="https://admin.example.com/login"
```

不支持通配符、前缀匹配、URL 用户信息、查询参数、片段或协议相对地址。留空时拒绝
OAuth 回跳。生产前端与 API 应位于同一站点并使用 HTTPS，以便携带 HttpOnly、SameSite
浏览器绑定 Cookie。跨站部署需另行设计安全的凭据交换流程。

授权成功仅回跳 `?oauth_code=...`，不再在 URL 中放访问或刷新令牌。
前端先清除 URL 参数，再通过 `POST /system/auth/oauth/code/exchange` 提交
`{"code":"..."}`，携带登录浏览器的 Cookie 获取令牌。授权码在 60 秒内有效、原子消费，
且绑定发起授权的浏览器。旧前端必须与后端一起升级。

## 文件处理

头像只允许完整解码并重新编码的 JPEG、PNG、GIF、ICO 位图；SVG/HTML/XML 不允许上传。
普通上传中的位图也会重编码，去除尾随内容和附带元数据。
下载路径解析真实路径后检查目录边界，并要求目标是文件，拒绝相邻同前缀目录及链接
到上传目录外的文件；下载仍受既有下载功能权限保护。

此次修改不会处理已上传的 SVG 文件。上线前应清理或隔离历史危险文件；用户上传文件
宜由独立来源提供，避免与管理后台共用来源。
